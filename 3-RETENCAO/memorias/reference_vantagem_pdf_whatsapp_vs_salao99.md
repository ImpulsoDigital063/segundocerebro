**Vantagem cravada Eduardo 25/05/2026 sobre o Salão99:**

No Salão99, o botão "Imprimir" da comanda abre menu com 2 opções:
1. "Exportar PDF" (baixa local)
2. "Enviar para o cliente..." (abre modal de e-mail · só envia por email)

No AgendaPRO, o botão "WhatsApp" da comanda usa Web Share API e abre o
seletor nativo do sistema:
- Em Android/iOS: cliente recebe o PDF anexado direto no WhatsApp
- Em desktop: abre seletor com WhatsApp Desktop, WhatsApp Web, Outlook,
  Copilot, etc · sem custo de integração nem necessidade de email

**Por que importa:**
- 99% dos donos de salão se comunicam com cliente via WhatsApp (não email)
- Salão99 desperdiça canal: gera PDF → manda email → cliente abre email
  depois → vê o PDF (atrito alto, taxa de abertura baixa)
- AgendaPRO: 1 clique → cliente recebe direto no WhatsApp (canal primário)

**Onde usar como argumento:**
- Copy da landing (`/`, `/salao`, `/barbearia`): mencionar "envia recibo
  por WhatsApp" como diferencial
- Pitch comercial pra Marko, Izanara e leads novos
- Posts/criativos comparativos pós-31/05 (Salão99 desliga)
