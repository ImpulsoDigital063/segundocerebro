### Regra arquitetural mobile/desktop · `agendapro/AGENTS.md`

Cravada em arquivo permanente do repo:
- Mobile (`agendapro.net.br`) e Desktop (`agenda-pro-seven` · piloto Palace) **compartilham codebase**
- Ajuste num lado NÃO pode mexer no outro
- Isolar via Tailwind responsive (`sm:` / `md:` / `lg:`)
- Mudança sem prefixo afeta TODAS as telas
- Mudança com `sm:` afeta só ≥ 640px (desktop)

Padrão obrigatório:
```tsx
// Ajuste só pra mobile: sem prefixo + anular no sm:
<div className="flex-1 min-h-[280px] sm:min-h-0 overflow-y-auto" />

// Ajuste só pra desktop: prefixo sm:
<div className="sm:max-w-md sm:rounded-3xl" />
```
