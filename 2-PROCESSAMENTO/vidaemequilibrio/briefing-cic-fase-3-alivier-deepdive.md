## 📦 Formato de entrega

**Um documento Markdown único** chamado `dossie-alivier-deep-dive.md`.

Para cada eixo (1-10):
1. **Achados crus** (citações, prints, URLs, dados verificados)
2. **Princípio extraível** (1-3 bullets — o QUE funciona ali, formulado como princípio replicável)
